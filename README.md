# Ритм → звук

Небольшой интерактивный эксперимент на чистом HTML/CSS/JavaScript и Web Audio API.

## Локальный запуск

Откройте `public/index.html` в современном браузере. Если браузер ограничивает AudioWorklet при открытии через `file://`, запустите локальный HTTP-сервер из корня проекта:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/public/

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и загрузите в него файлы из этого архива.
2. Оставьте `public/index.html` и `.github/workflows/pages.yml` в указанных каталогах.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **GitHub Actions** в качестве источника.
5. Отправьте коммит в ветку `main` (или измените имя ветки в `pages.yml`, если используете другую).
6. GitHub Actions соберёт и опубликует сайт. Ссылка появится в **Settings → Pages** и в успешном запуске workflow.

## О звуковом эксперименте

Эксперимент повторяет один цикл выбранной формы волны с регулируемой частотой. Низкие значения дают медленные колебания, высокие — слышимый тон.

Режим «Пиано-подобный» — синтезированная гармоническая форма волны, а не запись акустического пианино. Это сделано, чтобы проект был автономным и не зависел от стороннего аудиофайла. Эталонные ноты генерируются отдельно.

Детектор высоты анализирует выходной аудиосигнал через AnalyserNode и оценивает период методом автокорреляции.
